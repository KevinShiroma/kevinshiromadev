## 🚀 Como Executar Localmente

Para visualizar o site em sua máquina, clone o repositório e abra o arquivo `index.html` em seu navegador ou inicie um servidor local simples:

```bash
# 1. Clonar o repositório
git clone https://github.com/KevinShiroma/kevinshiromadev.git

# 2. Entrar na pasta do projeto
cd kevinshiromadev

# 3. Iniciar um servidor local (com Python)
python -m http.server 3000
```

Abra seu navegador em `http://localhost:3000`.
